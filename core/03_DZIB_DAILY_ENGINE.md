# DZIB Daily Engine

Estado: **PROMULGADO / IMPLEMENTADO EN LAB**

## Definición
DZIB Daily Engine detecta las actividades que el negocio necesita realizar para operar correctamente cada día.

## Fuentes
ADN empresarial, roles, funciones, procesos, operación real, The Wallet, señales y pendientes.

## Objetivo
Evitar que el empresario reconstruya mentalmente el rompecabezas operativo. La pantalla Hoy presenta las actividades críticas del día.

## Estructura mínima
Actividad, área, responsable, frecuencia, estado, criticidad, evidencia, dependencia, impacto en The Wallet y fuente/origen.

## D Capital — Daily List inicial
1. Revisar pagos esperados.
2. Atender vencidos y promesas de pago.
3. Registrar pagos y comprobantes.
4. Atender solicitudes de renovación.
5. Revisar colocaciones autorizadas por dispersar.
6. Conciliar bancos.
7. Confirmar cierre y cuadre.

## Aprendizaje operativo
El usuario puede agregar una actividad no detectada. Si se repite, es necesaria y tiene impacto operativo/financiero, DZIB OS puede proponer incorporarla al ADN operativo y al Daily List oficial.

## Principio
El Daily Engine no es una simple lista de tareas. Es la manifestación diaria del conocimiento que DZIB OS tiene sobre cómo funciona la empresa.

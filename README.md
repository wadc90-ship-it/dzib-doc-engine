# DZIB OS — Motor Documental

Repositorio de documentación institucional y memoria documental de DZIB OS.

## Estructura

- `core/` — Fuente de Verdad Documental del DZIB Core.
- `docs/` — documentación publicada/derivada.
- `src/` — motor documental.
- `templates/` — plantillas.
- `notion/` — integración documental con Notion.
- `config/` — configuración.
- `tests/` — pruebas.

## Memoria Documental Oficial

Estado: **ACTIVO desde 2026-08-13**.

Toda decisión declarada **autorizada, aprobada, corroborada o promulgada** debe quedar representada en los Markdown oficiales del Core y en el registro de promulgaciones.

Flujo:

**Conversación / laboratorio → decisión promulgada → actualización Markdown → implementación → registro de versión.**

Los HTML y demás prototipos son evidencia funcional; no sustituyen la Fuente de Verdad Documental.

Principio rector: **Complejidad por dentro. Claridad por delante.**
